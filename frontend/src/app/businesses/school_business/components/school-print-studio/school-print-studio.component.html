1. Choti Thermal Printer

80mm / 58mm

Fee counter par instant choti raseed nikalne ke liye use hota hai (e.g. Epson TM-T82, Xprinter XP-80/58). Is mein ink nahi lagti, sirf thermal paper roll dalta hai.

  1. Option A (Easy Windows/Mac): Printer USB/Wi-Fi se lagayen, default printer set karen — app Print / Save PDF dialog se khud 80mm ya 58mm format mein print kar dega.
  2. Option B (Direct 1-Click USB ESC/POS): Chrome/Edge mein neeche Connect USB Serial dabayen taake dialog ke baghair seedha print + cash drawer khule.
  3. Abhi machine nahi hai? Koi masla nahi — Save as PDF chunekar testing kar sakte hain.

2. A4 Office Laser / Inkjet

A4 Sheet

Bank ke 3-Copy Fee Challan, Exam Result DMC, Salary Slip, Student ID Cards aur Barcode Sticker Sheets nikalne ke liye regular office printer use hota hai.

  1. A4 printer ko PC/Laptop se USB ya Office Wi-Fi par connect karen.
  2. 3-Copy Bank Challan ke liye print dialog mein Landscape auto-select hota hai; Result, Salary & Stickers Portrait par aate hain.
  3. Parents ko WhatsApp par bhejne ke liye printer list mein Save as PDF select karen.
